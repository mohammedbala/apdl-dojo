# APDL Dojo

A gamified trainer that makes you fast at ANSYS Mechanical APDL, all the way to building a
turbine-generator tabletop foundation from scratch with four different techniques.

**Play it:** https://mohammedbala.github.io/apdl-dojo/

Type APDL in the browser. An in-browser APDL interpreter builds the model, a Three.js viewport
renders it next to the target, and a grader checks geometry, attributes, mesh and loads as you type.

Work in progress — see the full description at the end of the build.
